Design Alternatives Comparison

Based on the sketches, we evaluated three main design approaches for the AR tour application:

Approach A: Marker-Based AR

Uses physical markers placed at heritage sites for AR content triggering.

Strengths

  • High accuracy
  • Reliable content triggering
  • Consistent experience

Weaknesses

  • Requires physical markers
  • Maintenance overhead
  • Limits spontaneity

Approach B: GPS-Based AR

Uses GPS coordinates to trigger AR content when users approach heritage sites.

Strengths

  • No physical markers needed
  • Spontaneous exploration
  • Easy to scale

Weaknesses

  • Accuracy varies (5-50m)
  • Urban canyon issues
  • Battery drain

Approach C: Hybrid AR

Combines GPS positioning with visual recognition for optimal experience.

Strengths

  • Best accuracy
  • Flexible triggering
  • Robust experience

Weaknesses

  • Complex implementation
  • Higher development cost
  • More resource intensive

Decision & Rationale

Final Choice: Approach B - GPS-Based AR

After careful evaluation, we chose the GPS-Based AR approach as our primary implementation strategy. This decision was based on several key factors:

  1. User Convenience: No need for physical markers means visitors can spontaneously explore without preparation.
  2. Scalability: Adding new heritage points only requires updating coordinate data, not physical installation.
  3. Cost Effectiveness: Lower maintenance costs compared to marker-based systems.
  4. User Expectations: Modern tourists expect seamless, app-free experiences that work anywhere.

While GPS accuracy can be challenging in urban environments, we mitigate this with:

  • Virtual coordinate fallback for GPS failures
  • Extended detection radius (50m) to account for GPS drift
  • Visual feedback to guide users toward precise locations
